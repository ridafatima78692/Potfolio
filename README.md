# Personal Portfolio Project

This repository contains a multi-page personal portfolio website built with HTML5 and CSS3. The project is designed as a beginner-friendly portfolio assignment and is published through GitHub Pages.

## Student

**Name:** Rida Fatima

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- LinkedIn-ready portfolio content

## Website Pages

- `index.html` - Home page and portfolio overview
- `ABOUT.html` - Personal introduction and skills
- `EDUCATION.html` - Academic background
- `EXPERIENCE.html` - Work experience
- `HOBBIES.html` - Personal hobbies and interests
- `CONTACT.html` - Contact details and contact form
- `HOME.html` - Redirect page for old home links
- `HOOBIES.html` - Redirect page for misspelled old hobbies links

## Project Features

- Responsive layout for desktop and mobile screens
- Consistent navigation across all pages
- Semantic HTML structure
- Accessible skip link and current-page navigation state
- Styled contact form with text fields, select menu, checkboxes, radio buttons, and textarea
- Education table with accessible table structure
- Professional visual styling with reusable CSS variables
- GitHub Pages-compatible `index.html` root page

## Deployment

The website is configured for GitHub Pages. The root page is `index.html`, which allows the site to load correctly at the main GitHub Pages URL.
