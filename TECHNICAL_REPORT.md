## 1. Project Overview

The Personal Portfolio Project is a responsive multi-page website created to present a student's profile, education, experience, hobbies, and contact information in a professional online format. The website is built using HTML5 and CSS3, version-controlled with Git, and deployed through GitHub Pages.

The main purpose of the project is to demonstrate practical understanding of website structure, styling, navigation, forms, tables, responsive layout, and basic web publishing.

## 2. Objectives

- Apply CSS3 for professional styling and responsive design.
- Build multiple connected pages with consistent navigation.

## 8. CSS3 Implementation

The stylesheet `styles.css` controls the complete visual design. Important CSS features include:

- CSS custom properties through `:root`
- Flexbox for header and form option groups
- CSS Grid for page layouts
- Responsive media queries
- Hover and focus states
- Table styling
- Form styling
- Reusable card and panel components

## 9. Accessibility Features

The project includes several accessibility improvements:

- Skip link to jump directly to the main content.
- `aria-label` on main navigation.
- `aria-current="page"` for active navigation links.
- Proper labels for form fields.
- `fieldset` and `legend` for checkbox and radio groups.
- Table caption and scoped table headers.
- Visible focus states for keyboard navigation.

## 10. Responsive Design

The website adapts to different screen sizes using media queries:

- Large screens use multi-column layouts.
- Tablet screens reduce complex grids.
- Mobile screens stack content into single-column layouts.
- Navigation wraps cleanly on smaller screens.
- Tables are placed inside a horizontal scroll wrapper to prevent layout breaking.

## 11. GitHub Pages Deployment

GitHub Pages requires an `index.html` file at the root of the repository. The project includes this file, so the website can load correctly from the root URL.

Two redirect files are also included:

- `HOME.html` redirects to `index.html`.
- `HOOBIES.html` redirects to `HOBBIES.html`.

These redirect files prevent old or misspelled links from breaking.
